# Logical pin map

The pin map is documented in `../../docs/WIRING.md`: D2 left leg, D3 right leg, D4 left foot, D5 right foot, D8 ultrasonic TRIG, D9 ECHO, D13 buzzer. The UNO bench sketches each use only their necessary subset. Do not treat this logical map as a verified Nano shield header/power map; complete `../../hardware/electronics/SHIELD_CHECK.md` first.
