# First forward gait test

[`basic_walk.ino`](basic_walk.ino) is a command-driven first movement test for the assembled classic V9 robot. It uses the installed Servo library and Otto's D2–D5 mapping. The phase relationship follows the [official OttoDIYLib 13.0.0 walk](https://github.com/OttoDIY/OttoDIYLib/blob/f384c00a641e11c8741487320c6f1d82ad72e6d5/src/Otto.cpp), but with a smaller swing and a gradual start/stop. It does not use `Otto.h` because its `init` requires assigning an output pin for a buzzer, while no unused pin on this owner's current build has been verified.

Uploading does not move the robot. At 9600 baud, send `2`, `3`, `4`, or `5` to test just that Nano servo channel at 105° → 75° → 90°, holding each off-center position for three seconds. Send `p` for one small, supported preview (leg amplitude 8°, foot amplitude 6°); send `f` only after the preview and individual channel checks pass, the robot stands at neutral, and there is floor clearance and cable slack. `f` runs one bounded forward gait cycle (leg amplitude 20°, foot amplitude 12°, foot offset ±2°). Each command ends at 90° neutral, with the servos still attached to hold the stance. `h` holds neutral; `x` aborts an active gait and returns to neutral. Switch off servo power immediately if a joint binds, heats, or chatters.

The Nano may be on USB during this test only with the battery-to-Nano RUN lead removed. All four servo red wires must use the separate regulated 5 V, ≥3 A source; join its GND to Nano GND. This sketch assumes the four servos are installed in the official left-leg/right-leg/left-foot/right-foot order and that horns were mounted near neutral. Direction and actual floor translation must be observed, not inferred from serial output.
